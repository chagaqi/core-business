### [Skill created] Vendor featured-placement outreach (PeptidesFinder)
Use to find peptide vendors ranked below PeptidesFinder's paid featured slots and draft featured-placement upsell outreach. Runs daily via the vendor-outreach trigger.

> **## Purpose**
> PeptidesFinder (peptidesfinder.com) is an independent directory that reviews/ranks research-peptide vendors and sells **paid "featured" placement** (featured slots sit above all other vendors on every filtered directory view). This play finds the strongest-rated vendors that are NOT in a featured slot and drafts a punchy featured-placement upsell to each. These are warm: PF already reviews them and sends them buyer traffic.
>
> **## Target selection (warmest first)**
> Source of truth is PF's own directory:
> - Online stores: https://peptidesfinder.com/vendors/online (paginated `?page=N`, ~41 pages, sorted featured-first then rating)
> - Wholesale: https://peptidesfinder.com/vendors/wholesale
> Each run:
> 1. Scrape the online-stores listing starting from the highest-rated non-featured vendors (rating 4.9 → down). The top 3 slots are FEATURED (paid) — skip those; target the high-rated vendors ranked directly below them.
> 2. Pick the batch size the trigger specifies (default 10), warmest-first, that have NOT already been worked. Track worked vendors in this play's execution history / company records — never re-draft a vendor already contacted.
> 3. For each target vendor, scrape their own site (homepage + /contact) to get: a real contact email, ships-from location, catalog size, and any standout trait (money-back guarantee, cGMP/US manufacturing, Janoshik verification, own affiliate program, unusually deep catalog).
>
> **## Contact enrichment**
> Vendors are gray-market and NOT in standard B2B databases (Explorium/Apollo return nothing). Get emails by scraping the vendor's own contact/about pages (swan-fetch-scraped-url). Common patterns: support@, cs@, info@, contact@. If no email is found after checking homepage + /contact + /about, skip the vendor and pick the next-ranked one — never invent an address.
>
> **## Angle (see /reach-out skill for voice — direct/punchy, recorded there)**
> Core hook, unique per vendor: "You're rated {X} and ranked #{N}, but the slots above you are PAID, not better-rated — buyers comparing sources see them first and never scroll to you." Anchor each draft on that vendor's real standout trait (the thing that deserves the top slot). One CTA: offer the numbers on a featured slot. Never a feature list, never invented stats. Follow the /reach-out final gate + Humanizing Outreach.
>
> **## Output**
> - If an email sender is connected: stage a one-step (or short) email sequence per vendor via the sequencer for approval, using the connected sender.
> - If NO sender is connected: draft the email copy (subject + body + the vendor's contact email) and create ONE consolidated review task on the desk with all drafts, so the user can review now and send once their inbox connects.
> Either way: never auto-send. Every draft waits for explicit approval.
>
> **## Guardrails**
> - One shot per vendor — dedupe against prior runs.
> - Do not blast; respect the per-run batch size.
> - Skip any vendor already in an active conversation or already a paying/featured customer.
