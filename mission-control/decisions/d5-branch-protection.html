D5 — Turn on branch protection (you have Pro now, so this works)

One-time, ~60 seconds, in the GitHub UI
What it does: makes it physically impossible for anyone (including an AI agent following stale instructions at 3am) to push broken code to main. Merges require a pull request with the CI check green. This is the single highest-leverage $4 in the budget.
  1. Open github.com/chagaqi/core-business → Settings → Rules → Rulesets → New branch ruleset
  2. Ruleset name: protect-main · Enforcement status: Active
  3. Target branches: Add target → Include default branch
  4. Tick Require a pull request before merging — set required approvals to 0 (you're solo; CI is the reviewer)
  5. Tick Require status checks to pass → search and add verify + engine tests
  6. Click Create. Done.

After this, tell Claude "ruleset is on" and the board gets updated. From then on: sprint branch accumulates work → PR → CI badge goes green → you click merge.
